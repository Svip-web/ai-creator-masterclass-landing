# Локальна копія SMM-лендінгу

Статична локальна версія сторінки `https://smm.newlook.ua/smm/reg148`.

## Запуск

Відкрийте `index.html` подвійним кліком або запустіть локальний сервер у цій папці:

```powershell
npx --yes serve -l 8080 .
```

Після цього відкрийте `http://localhost:8080`.

Форма працює в демонстраційному режимі: перевіряє введені дані, але нічого не надсилає назовні. На сторінці немає сторонньої аналітики, рекламних пікселів або залежності від Webflow.
