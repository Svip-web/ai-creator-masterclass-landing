Робоча статична версія: `../../record-ua/`.

https://svip-web.github.io/ai-creator-masterclass-landing/record-ua/

## Збірка та перевірки

Потрібен Node.js 20 або новіший. З цього каталогу:

```powershell
npm ci
npm run build
npm test
npm start
```

Локальний перегляд: http://127.0.0.1:4188/. Збірка створює `dist/`; для оновлення GitHub Pages скопіюйте його вміст у кореневий каталог репозиторію `record-ua/` і закомітьте зміни.

```powershell
Copy-Item -Path '.\dist\*' -Destination '..\..\record-ua' -Recurse -Force
```

## Структура

- `src/index.html`, `src/styles.css`, `src/css/` — український текст і оформлення.
- `src/config.js` — Bunny-відео, CRM та публічні ID аналітики. У `dist/config.js` плейсхолдер обкладинки замінюється готовим шляхом.
- `src/js/` — форма, перевірка й нормалізація телефону, відкладені ресурси та аналітика.
- `src/vendor/`, `src/fonts/`, `src/images/` — локальні бібліотеки, шрифти, прапорці та адаптивні обкладинки.
- `tests/` — CRM-контракт, реальна бібліотека телефонів, повторні завантаження, стиснення й кешування локального сервера, рекламні події.
- `build.mjs` — мінімізація, бандл, хешовані ресурси, перевірка шляхів. Звіт записується в ігнорований `optimization/build-manifest.json`.

`tests/ui-server.mjs` запускає окремий інтерфейс на порту 4189 з локальною імітацією CRM. Звичайна форма та `npm start` використовують справжній CRM-обробник. Реальна тестова угода під час розробки не створювалася.

Теги та маршрут консультації описані в `../../record-ua/README.md`. Числовий етап узято з інших форм Creator; назва етапу та реальне надходження угоди в самому CRM-кабінеті залишаються неперевіреними.
