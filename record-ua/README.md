## Налаштування

`config.js` містить посилання на Bunny-відео, CRM-пресет та публічні ID аналітики.

- Назва угоди: `Консультация  запись  АІ Creator UA`.
- Product: `Ai-creator`; етап: `105820611`; теплота: `Теплый`; req: `etsy_no_pay_4`.
- Теги: `запись`, `консультация`, `бронь_20€`, `390€`, `590€`, `790€`.
- Маршрут взято з інших консультаційних форм проєкту. Назву етапу «Новый лид» у CRM-кабінеті та фактичне надходження реальної угоди ще не перевірено.

Код країни вже задається перемикачем телефону. Для України приймаються національний номер, номер із початковим 0 та повний номер із 380 / +380 / 00380. У CRM передається єдиний міжнародний номер без дублювання коду.

Відео запускається одним натисканням на локальну обкладинку. Ресурси телефонного поля завантажуються при відкритті форми. Meta та Google Ads конверсії надсилаються лише після успіху CRM; локально аналітика вимкнена.

Форма після валідного надсилання звертається до справжньої CRM. Автоматичні й локальні UI-тести використовують імітацію та не створюють реальних угод.

GitHub Pages використовує власні правила стиснення й кешування; `.htaccess` та `_headers` призначені для інших сумісних хостингів.
