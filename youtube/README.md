# AI Creator — YouTube

Мобільна світла сторінка: https://svip-web.github.io/ai-creator-masterclass-landing/youtube/

Готові статичні HTML, CSS, JavaScript, шрифти та зображення. Збірка й зовнішні залежності не потрібні. Відносні шляхи працюють у підпапці GitHub Pages.

Актуальний дизайн: Furore, великий портрет, червоні кнопки з постійним градієнтним переливанням, анімовані іконки й цінники поверх фото, відступи секцій 48px, заокруглення сірих фонів 30px.

Форма поки в режимі попереднього перегляду: маска телефону працює локально, реєстрація вимкнена до вибору воронки. Дані нікуди не надсилаються.
