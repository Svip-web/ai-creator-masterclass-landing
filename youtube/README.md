# AI Creator — YouTube

Мобільна світла сторінка: https://svip-web.github.io/ai-creator-masterclass-landing/youtube/

Готові статичні HTML, CSS, JavaScript, шрифти та зображення. Збірка й зовнішні залежності не потрібні. Відносні шляхи працюють у підпапці GitHub Pages.

Актуальний дизайн: простий Helvetica Neue, великий портрет, червоні кнопки з постійним градієнтним переливанням, анімовані іконки й цінники поверх фото, відступи секцій 48px, заокруглення сірих фонів 30px.

Форма підключена за схемою оригіналу: підтвердження CRM → SmartSender → персональний перехід у Telegram. Маска з локальною бібліотекою завантажується після наміру натиснути CTA або відкриття форми; до готовності телефону кнопка надсилання недоступна. Повтор після збою SmartSender використовує вже підтверджену заявку, не дублюючи її в CRM.

Збережено GTM-PQX4ZSHP, початкові Meta PageView та чотири Meta Lead після підтвердження CRM. Google Ads використовує тригер форми в оригінальному GTM. Навіть невалідний браузерний submit може створити рекламну конверсію: перевірки надсилання виконувати лише з підставним transport, без реальних заявок.

Оптимізована версія має вбудовані стиснуті стилі й один defer-скрипт. Телефонні CSS/core/utils не завантажуються на початковому екрані. WebP/AVIF мають responsive srcset, зображення нижче першого екрана — lazy loading, шрифти — локальні Helvetica Neue WOFF2. Декоративні анімації призупиняються поза екраном; постійний градієнт кнопок збережений.
